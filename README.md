# LearnLanguages

Projekt jest projektem inżynierskim dwóch studentów informatyki Politechniki Śląskiej: Radosława Stałęgi i Wojciecha Wasika.

Ogólny opis projektu
Projekt jest aplikacją desktopową służącą do nauki języków obcych. Aplikacja ma na celu naukę języka angielskiego, natomiast jest zaprojektowana tak, by móc rozszerzyć ją o inne języki. Posiada 2 główne moduły: fiszki - karty do nauki słówek - oraz moduł zadań generowanych przez LLM.

Wykorzystane technologie, architektura
Aplikacja jest napisana w środowisku .NET z użyciem frameworku WPF. Głównym językiem programowania jest C#, natomiast do warstwy graficznej użyto XAML. Wykorzystano bazę danych (... uzupełnić)
